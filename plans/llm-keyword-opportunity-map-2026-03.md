## 2) Core shift: SEO keywords → LLM questions

Traditional SEO often targets short phrases:
- `vedanta philosophy`
- `japa meditation`

LLM search behavior is more likely to be:
- “I’m spiritually curious but skeptical. Where should I start in Hindu philosophy?”
- “Is japa or silent meditation better for anxiety?”
- “Can I study Vedanta without converting?”

So Sadhaka should prioritize keyword targets that are:
- **question-led**
- **decision-led**
- **beginner-safe**
- **comparison-rich**
- **emotion/problem contextualized**

## 3) Intent buckets to target

### Bucket A — Definition + Orientation
For users asking “What is X?” and “Where do I begin?”

### Bucket B — Comparison + Difference
For users trying to disambiguate two paths/concepts.

### Bucket C — Decision / Chooser
For users seeking personalized recommendations.

### Bucket D — Beginner Implementation
For users asking how to start safely and consistently.

### Bucket E — Problem/Situation-based
For users framing questions through anxiety, overthinking, busy life, etc.

### Bucket F — Meaning / Sanskrit Concepts
For users asking exact term meanings and philosophical distinctions.

## 7) Page-format blueprint for LLM retrieval

Each target page should begin with:
1. **Direct answer in first 2–3 lines**
2. **Best for / Not best for** block
3. **Decision table** (clear differences)
4. **FAQ with prompt-language questions**
5. **“If you are X, start here” next-step section**

This format improves:
- extractability for AI summaries
- answerability in Google AI Overviews
- conversion from “question” to “next action”
