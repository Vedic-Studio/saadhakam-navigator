### Visual style patterns (what works in the niche)

- **Traditional temple deity photography** (ganapatyarya) — high trust signal, real-world.
- **AI-generated cosmic / divine imagery** (KrishnaDharma, WordsSlay) — works only when high-craft (cinematic, blue/gold/saffron palettes). Generic AI imagery reads cheap.
- **Sacred geometry + nature** (yajnshri) — bridges modern wellness aesthetic.
- **Manga / anime treatment of epics** (prachyam7) — hits young audience hard.
- **Handwritten/personal artifacts in headers** (Priya_Kruthi) — intimate, trust-building.
- **Devanagari Om + trishul motifs** — universal in this niche.

### Reference / citation behaviors

- **Verse numbers are a credibility signal** (Rigveda_Online, KrishnaDharma, SanjeevSanskrit). Sadhaka must always cite chapter:verse, not "as the Gita says".
- **Named acharyas / commentators** (KrishnaDharma) raise authority. Use Shankara, Ramanuja, Madhva, Abhinavagupta etc. by name, not "the commentators say".
- **Cross-references between texts** (rian_vlbt, SanjeevSanskrit) signal depth.

### Anti-patterns visible in the niche (Sadhaka must NOT replicate)

- **Political overlays** (WordsSlay, others). The moment "Modi as sacred return" appears, Sadhaka loses its philosophical-authority positioning. Hard skip.
- **Astrology dependence** (ganapatyarya, shreemastrology, YogmayaAstro5). Sadhaka is a philosophy / practice / text platform, not an astrology platform. Hard skip.
- **Bot-style verse spam without commentary** (Rigveda_Online). Doesn't build community, gets low engagement after the novelty passes.
- **"The secret the gurus won't tell you" hooks**. Clickbait, not Sanatan voice.
- **"Hindu" framing as default identity tag**. Sadhaka uses "Sanatan" or names the school. Per CLAUDE.md voice rules.
- **Em dashes in prose**. Per CLAUDE.md, never. Use periods, commas, line breaks.
- **Sensational claims without claim-file backing**. "Sushruta invented plastic surgery", "Surya Siddhanta = NASA" type claims. Per `kb/INDEX.md`, every such claim must trace to `kb/claims/*.md` with verdict tags.
- **Conspiratorial / outbreak-response discourse** (iamkamyabuch lapses into this). "Modernity is a coordinated assault" framings. Sadhaka critiques modernity from tradition-as-strength, not from tradition-as-besieged.
- **Reactive identity defense** (VedicWisdom1, SammyVada). "Countering propaganda against Hinduism", "remember what you represent" framings. Sadhaka stays affirmative and text-anchored. If a draft starts policing how readers should perform their Hinduness, kill it.
- **High-certainty doctrinal assertions without `kb/claim` backing** (VedicWisdom1 tendency). Sadhaka's confidence comes from cited sources, not from rhetorical certitude.
- **Course-funnel-as-content** (VedicWisdom1). Don't write posts whose primary purpose is selling a course. Posts can mention products at the end if the post stands on its own as content first.

### Borrow-with-caution patterns

Some peer formats are useful structurally but tone-risky. Use them only with explicit gates:

| Pattern | Source | Gate |
|---|---|---|
| Aphoristic admonition | SammyVada | Must cite specific text (Manusmriti, Niti, etc.). Must address conduct from text, not from culture. |
| "Ancient solutions for modern crises" | iamkamyabuch | Must name a specific text and a specific modern problem. No generalized "modernity is sick" framing. |
| Course / offer funnel | VedicWisdom1 | Only when Sadhaka actually has a course or newsletter to offer. Content must stand alone first. |
| High-certainty thesis | VedicWisdom1 | Only when `kb/claims/*.md` supports the thesis with PRIMARY-SOURCE-LEVEL verdict. Otherwise hedge. |
