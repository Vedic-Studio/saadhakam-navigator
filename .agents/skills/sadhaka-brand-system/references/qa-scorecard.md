# QA Scorecard — Sadhaka Brand System

Score each category 0–5.

- **0** = absent / broken
- **3** = acceptable but inconsistent
- **5** = strong and system-aligned

## 1) Brand & Trust Integrity

- [ ] Tone is warm, scholarly, and non-preachy.
- [ ] Messaging avoids coercive or guru-marketing language.
- [ ] Trust posture is clear before conversion asks.
- [ ] Neutral/non-sectarian framing is preserved.

## 2) Information Architecture

- [ ] Page follows trust-first sequence (orientation → foundation → depth → proof → CTA → FAQ).
- [ ] Sections have single clear purpose and no narrative collisions.
- [ ] Navigation taxonomy matches seeker mental model.

## 3) CTA Hierarchy & Conversion Logic

- [ ] One primary CTA is clearly dominant.
- [ ] Secondary CTAs support exploration, not competition.
- [ ] Conversion ask appears after sufficient context/proof.

## 4) Design Language Fidelity

- [ ] Dark premium base with disciplined accent usage.
- [ ] Serif/sans hierarchy is used intentionally.
- [ ] Surfaces, spacing, and radii reflect calm premium quality.
- [ ] Motion is subtle and meaning-supportive.

## 5) Component System Quality

- [ ] Hero communicates value + direction in one pass.
- [ ] Pillars establish coherent foundation.
- [ ] Depth sections demonstrate real authority.
- [ ] Product bridge feels supportive, not salesy.
- [ ] Social proof is credible and contextually placed.
- [ ] FAQ resolves major trust objections.

## 6) Accessibility & Responsiveness

- [ ] Contrast/readability is strong across dark surfaces.
- [ ] Keyboard/focus states are visible and usable.
- [ ] Hierarchy remains clear on mobile.
- [ ] Sticky/mobile CTA is useful and dismissible.

## 7) Adaptation Quality (Cross-Project)

- [ ] Invariants are preserved.
- [ ] Variables are intentionally adapted to new audience/product.
- [ ] No shallow “visual clone” artifacts that break category fit.

---

## Scoring Bands

- **30–35**: Strong match, launch-ready.
- **22–29**: Good direction, revise weak areas.
- **0–21**: Misaligned, rework architecture and positioning.

## Required Fix Rule

Regardless of total score, launch is blocked if any of these are below 3:
- Brand & Trust Integrity
- CTA Hierarchy & Conversion Logic
- Accessibility & Responsiveness
