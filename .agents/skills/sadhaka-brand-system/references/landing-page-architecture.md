# Landing Page Architecture

This is Sadhaka’s canonical trust-first fold logic derived from homepage implementation.

## Canonical Fold Sequence

1. **Hero**
2. **Pillars / Foundation**
3. **Knowledge Depth (Teachings/Texts)**
4. **Worldview / Philosophical Context**
5. **Civilizational Credibility Frame**
6. **Product/AI Introduction (Subtle)**
7. **Social Proof & Trust Signals**
8. **Primary Conversion Section**
9. **FAQ / Objection Handling**

## Section Purpose Rules

### 1) Hero
Goal:
- establish existential relevance,
- position Sadhaka as guide,
- present one clear primary CTA.

Must include:
- high-trust framing,
- immediate orientation,
- primary + secondary action hierarchy.

### 2) Pillars
Goal:
- define intellectual and cultural foundation,
- prove the system is grounded, not trend-driven.

### 3–5) Depth + Context Layers
Goal:
- demonstrate educational authority,
- teach before selling,
- contextualize tradition and scope.

### 6) AI/Product Framing
Goal:
- introduce product as companion, not replacement for tradition.

### 7) Social Proof
Goal:
- reinforce trust using outcomes + scale signals.

### 8) Conversion
Goal:
- re-ask with clarity after trust has been earned.

### 9) FAQ
Goal:
- neutralize skepticism and category confusion.

## CTA Hierarchy

- One primary CTA repeated consistently (header, hero, final conversion block, mobile sticky).
- Secondary CTAs route to educational exploration (texts, philosophies, traditions).

## Navigation Logic

Top-level nav should mirror seeker mental model:
- Philosophies
- Texts
- Practices
- Traditions

This supports broad entry while preserving coherent discovery.

## Structural Guardrails

- Don’t move social proof above foundational context on trust-sensitive pages.
- Don’t introduce hard-sell CTA before educational credibility is established.
- Don’t overcrowd hero with competing product claims.
