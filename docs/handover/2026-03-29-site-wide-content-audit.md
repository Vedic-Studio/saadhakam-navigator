## Scoring Rubric (6 dimensions, 10 pts each = 60 max)

| Dimension | What it measures |
|-----------|-----------------|
| **Directness** | Leads with the claim, no warmup. Direct answer block present and strong. |
| **Rhythm** | Sentence variety, no run-ons, no monotone paragraph blocks. |
| **Trust** | Every claim attributed to source text + named person. Numbers verified. |
| **Authenticity** | Zero slop phrases, zero strawman negations, no marketing filler. |
| **Density** | Every paragraph advances meaning. No redundancy, no padding. |
| **Focus** | Page serves one clear purpose. No scope creep, no tangential sections. |

**Thresholds**: 42+/60 = publish-ready | 35-41 = needs polish | <35 = needs rewrite

## Quality Gates (apply to ALL sessions)

Every session must pass before committing:

1. **Dash Gate**: Zero prose em dashes in modified files
2. **Polarity Gate**: No strawman negations in modified files
3. **Slop Scan**: Zero hardban phrases in modified files
4. **Attribution Gate**: Every doctrinal claim cites source text + named person/verse
5. **Number Gate**: Every stat traces to verified source file count
6. **Score Gate**: 42+/60 on rubric before merge
7. **Build Gate**: `npm run build && npm run lint && npm run test:run` passes
8. **Link Gate**: All internal links in modified files resolve to real routes

## Grep Verification Commands

Run after every session:

```bash
# Hardban slop phrases (must return zero for modified files)
grep -riE "ocean of wisdom|ancient wisdom|timeless wisdom|rich tradition|dive deeper|explore the depths|delve into|tapestry|landscape|transformative|profound|unlock" src/app/texts/page.tsx src/app/traditions/page.tsx [etc]

# Em dashes in prose (must return zero)
grep -n "—" [modified files] | grep -v "href\|url\|canonical\|import\|//"

# Journey/navigate
grep -riE "\bjourney\b|\bnavigate\b" [modified files]

# Unverified social proof
grep -riE "thousands of|millions of|countless|innumerable" [modified files]
```
