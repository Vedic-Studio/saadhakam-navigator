# Book Engine — Cult-Favorite Non-Fiction Mechanics for Sadhaka

**Purpose**
A reverse-engineered system for producing a cult-favorite book on Sanatan Dharma — one that circulates on X, Reddit, and private group chats, gets copy-pasted, passed hand-to-hand, and re-read annually.

**Sources studied**
- *The Red Pill Sidebar* (2015–2017, r/TheRedPill curated anthology) — 370 pages, ~80–120 posts, multi-author anthology
- *Bronze Age Mindset: An Exhortation* (Bronze Age Pervert, 2018) — ~220 pages, single-author, 77 numbered sections across 4 Parts

These are not models to imitate in content. They are **pressure vessels** — studied here only for the mechanics that let taboo, counter-cultural, or high-conviction ideas reach readers in a form that sticks. The Sadhaka book will carry content that is in the opposite spiritual direction, from a tradition that predates both by millennia. The engine is tooling; the substance is Sanatan.

## How to use this engine

**When writing a new post/section of the Sadhaka book:**
1. Pick a template from [09-templates-kit.md](09-templates-kit.md) that matches the section's job (framework? confessional? aphoristic coda? mini-myth?).
2. Pull the corresponding LLM prompt from [10-prompt-engine.md](10-prompt-engine.md).
3. Enforce voice rules from [02-voice-system.md](02-voice-system.md) and rhetoric rules from [04-rhetoric-and-conviction.md](04-rhetoric-and-conviction.md) in the draft pass.
4. Run the draft through the anti-pattern checklist in [08-sadhaka-transposition.md](08-sadhaka-transposition.md) §"Anti-patterns" — catch anything that slipped in from BAM's cruelty or TRP's misogyny.
5. Aphorism audit: [07-reader-assimilation.md](07-reader-assimilation.md) §"Density target" — at least one pull-quote-worthy line per 350 words.

**When planning the book as a whole:**
- Sequencing logic: [03-structure-system.md](03-structure-system.md) §"Spiral, not linear"
- Opening move: [05-edgy-ideas-playbook.md](05-edgy-ideas-playbook.md) §"Opening moves"
- Ending move: [07-reader-assimilation.md](07-reader-assimilation.md) §"Close with peace, not crescendo"

**When editing for sharability:**
- [07-reader-assimilation.md](07-reader-assimilation.md) §"Why readers copy-paste" — checklist for surface-ability

## Scope of this package

This package is **engine only**. It does not:
- Draft the book or any of its sections
- Decide the book's title, cover, spine length
- Set editorial priorities or chapter lineup
- Commit to a publication path

Those are subsequent decisions, made with this engine already in hand.

## Authorship convention (when the book is eventually written)

The Sadhaka book will likely publish under an author name (the founder's name or a pseudonym) — not anonymous. This is a deliberate divergence from BAM. See [02-voice-system.md](02-voice-system.md) §"Persona architecture for a named author" for the adaptation.
