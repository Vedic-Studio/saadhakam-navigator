# Writer Article Skill (Long-form / Guide Overlay)

Applied on top of `base.md` for topic hubs, guides, and sacred text pages.

## Additional Structure Requirements

### Word Count Targets
- Topic Hub: 800–1,200 words
- Combinatorial (practice for goal): 1,200–1,800 words
- Sacred Text Chapter: 2,500–3,500 words
- Sacred Text Shloka: 1,500–2,000 words
- Sanskrit Lexicon Entry: 1,000–1,500 words

### Expanded Intro (for long-form)
- Para 1: Define the concept with its Sanskrit origin if applicable
- Para 2: Historical or scriptural context (which tradition, which text, which period)
- Para 3: Why a modern seeker should study this now

### Pull Quotes
- For sacred text pages: include at least one key verse (Devanagari optional, transliteration required, English translation required)
- Format:
  ```
  > *"Verse transliteration"*
  > — Source (Book.Chapter.Verse)
  ```

### Structuring Long Content
- Use a logical narrative arc: definition → context → practice → integration
- Each major section should reference at least one specific traditional source
- Avoid generic transitions like "Furthermore" or "Additionally"; use topical bridges instead

### Comparison Tables (when relevant)
- For combinatorial pages: include a brief 2-column table comparing the practice to a related one
- For tradition pages: optional comparison across 2–3 schools on one key point
