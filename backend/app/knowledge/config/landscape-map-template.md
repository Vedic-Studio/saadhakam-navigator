# Domain Landscape Map Template

Every domain landscape map follows this structure. The parser extracts each section by heading.

---

## Frontmatter

Each file starts with YAML-style frontmatter:

```
slug: domain-slug
title: Full Domain Name
aliases: [alias1, alias2, alias3]
```

## Sections

### Territory

1-2 paragraphs. What this domain covers. Where it sits in the broader Sanatan philosophical tradition. What distinguishes it from adjacent domains. What a writer needs to know to position an article correctly within this space.

### Lineage & Key Figures

Bullet list. Founders, major commentators, schools, and root texts. Include approximate dates or era. Focus on figures a writer might need to reference or distinguish.

### Core Concepts

5-8 items. Each as `- **Term** — one-line definition`. These are the central ideas a writer must understand to write accurately in this domain. Use the concept's Sanskrit name with English gloss.

### Common Misreadings

Bullet list. What Western audiences, pop spirituality, or casual introductions get wrong about this domain. Each item names the misreading and the correction. These become opportunities for articles to differentiate.

### Internal Tensions

Bullet list. Debates, disagreements, or unresolved questions within the tradition itself. Not external critiques. These show philosophical depth and prevent articles from presenting a monolithic view.

### Modern Bridges

Bullet list. Domain-specific connections to modern concepts the target audience already understands. References `modern-bridges.md` for the universal bridge vocabulary. Each bridge names the traditional concept, the modern frame, and where the analogy breaks.

### Adjacent Domains

Bullet list. Which other landscape maps share borders with this one. Names the slug of the adjacent domain and one line on what they share and where they diverge.

---

## Length Target

400-600 words per map. Dense, specific, no filler. Every sentence should help a writer orient in the domain.
