# Modern Bridges Reference

Bridge vocabulary mapping traditional concepts to modern frames the target audience already understands. Used by Layer 2 (audience profile) and Layer 3 (domain landscapes).

---

## Universal Bridges (all domains)

### Consciousness & Reality
- **Brahman** — the substrate/source code of reality
- **Maya** — simulation theory, but consciousness IS the hardware, not separate from it
- **Adhyasa** — VR headset you forgot you put on
- **Lila** — open-world sandbox game played for its own sake
- **Samsara** — respawn loop; same player, different character

### States of Consciousness
- **Turiya** — the screen always on regardless of which movie plays
- **Waking/Dream/Deep Sleep** — three apps running on one OS
- **Samadhi** — flow state turned inward; complete absorption
- **Lucid dreaming** — recognizing you're dreaming while still in the dream

### Practice & Liberation
- **Moksha** — not escaping the simulation; recognizing you're both the player and the game
- **Karma** — accumulated code that shapes your next render
- **Jnana** — seeing the 3D image in a Magic Eye picture
- **Sadhana** — training protocol, not belief system
- **Diksha** — access credentials + mentorship
- **Mantra** — consciousness technology, not prayer or affirmation

### Philosophical Frameworks
- **Vyavaharika/Paramarthika** — game world vs hardware reality
- **Pratyabhijna** — "I've been wearing VR this whole time"
- **Bhakti** — structured emotional-aesthetic relationship with the divine
- **Dharma** — operating system of reality; natural law
- **Yoga** — cessation of mental fluctuations; the stilling, not the stretching

## Domain-Specific Bridges

### Advaita Vedanta
- Rope-snake → optical illusion; mismatch between data and interpretation
- Two reality levels → lucid dream recognition
- Neti neti → process of elimination debugging

### Kashmir Shaivism
- Spanda → quantum field theory; vibration as substrate
- Five acts of Shiva → game engine cycle (create, sustain, dissolve, conceal, reveal)
- Svatantrya → open-source consciousness

### Yoga-Samkhya
- Chitta-vrtti-nirodhah → noise-canceling headphones for consciousness
- Purusha/Prakriti → observer vs observed; the witness pattern

### Tantra
- Body as microcosm → hardware IS software
- Chakras → cosmological correspondence points, not energy centers
- Shaktipata → plugging into a power source

### Bhakti/Vaishnavism
- Five rasas → five relationship modes in game design
- Prapatti → cat carrying kitten vs monkey clinging to mother
- Avatar → philosophical claim about divine engagement with the simulation

## Usage Rules

1. Use 1-2 bridges per article section, not all at once
2. Lead with the bridge, then introduce the traditional term
3. Always name the break point where the analogy fails
4. The bridge is an on-ramp, not a destination
5. The tradition must feel MORE sophisticated than the modern frame, never equivalent
6. Never use a bridge that flattens the concept (e.g., "karma is just cause and effect")
